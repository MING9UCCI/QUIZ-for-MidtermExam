# 시험 전날 · MIDTERM QUEST

모바일에서 데이터베이스·인공지능·소프트웨어공학·반도체와 생성형 AI 디자인을 각각 복습하는 픽셀풍 학습 게임입니다. 제공된 강의자료를 바탕으로 직접 만든 **데이터베이스 40·인공지능 40·소프트웨어공학 100·반도체와 생성형 AI 100문제, 총 280문제**를 담았습니다.

**플레이 주소:** https://ming9ucci.github.io/QUIZ-for-MidtermExam/

## 개념 모험 (v1.3)

홈의 **개념 모험 시작**에서 짧은 개념 설명을 읽고 직접 조작하는 실습을 시작합니다. 암기 여부를 묻기 전에 원리가 어떻게 동작하는지 관찰하도록 구성했습니다. 제한 시간이나 실패 벌점은 없으며, 첫 완료에만 30 XP를 줍니다. 기존 퀴즈 진행은 별도로 보존합니다.

| 과목 | 체험 스테이지 |
|---|---|
| 데이터베이스 | 행·열 필터로 SELECT/WHERE 관찰, 회원 등록으로 기본 키 제약 체험, INNER/LEFT JOIN 결과 비교 |
| 인공지능 | K-NN 이웃 투표, K-means 배정·평균 중심 이동, 직선 조절과 평균제곱오차 관찰 |
| 소프트웨어공학 | 아래 10클래스 개발 길드 코스 |
| 반도체와 생성형 AI | 아래 4스테이지 (GAN 경쟁, 무어의 법칙·로그 스케일, 디퓨전 파라미터, 메모리 계층·HBM) |

| 순서 | 클래스 | 플레이 |
|---|---|---|

| 2 | 폭포 공사 현장 | 초기 요구 검토와 후반 변경의 재작업 비교 |
| 3 | 시제품 대장간 | 화면 기능을 켜고 끄며 두 차례 고객 피드백 반영 |
| 4 | 위험 탐사 나선 | 위험 실험 후 진행·보류를 결정하고 고객 평가 |
| 5 | 스프린트 원정대 | 용량 5칸의 백로그 선택, 진행·제품 검토·팀 회고 |
| 6 | 코드 수리소 | 공통 함수 추출, 할인 추가로 달라진 시험 결과 비교 |

각 클래스는 자유롭게 시작할 수 있고, 완료한 클래스에는 체크가 남습니다. 코스 지도에서 다음 미완료 클래스를 추천합니다. **10클래스 첫 완주 시 개발 길드 마스터 배지와 100 XP**를 한 번만 받습니다. 기존 3개 소프트웨어공학 클래스의 식별자와 기록은 유지했습니다.

### 반도체와 생성형 AI · 4스테이지

| 순서 | 스테이지 | 플레이 | 강의 |
|---|---|---|---|
| 1 | 위조 화가와 감정사 | 생성자·판별자를 번갈아 학습시켜 속이기와 잡아내기를 관찰 (진 쪽만 배울 수 있음) | 3주차 2차시 |
| 2 | 무어의 시계 | 2년씩 넘겨 트랜지스터 수 32배를 추적하고 선형·로그 스케일 비교 | 4주차 1·2차시 |
| 3 | 노이즈 정원사 | 시드·스텝·CFG를 바꿔 노이즈에서 별 그림 생성. 같은 시드 재현, 다른 시드 비교, CFG별 프롬프트 일치도 | 6주차 2차시 |
| 4 | 기억의 집 | SRAM(책상)·DRAM(책장)·NAND(도서관)에서 꺼내 보고, 일반 DRAM과 HBM으로 같은 데이터를 전송해 비교 | 7주차 1·3차시 |

픽셀 그림, 단계 수, 시간 단위, 통로 수, 프롬프트 일치도는 원리를 보여 주기 위해 직접 정한 단순화이며 실제 모델이나 반도체의 측정값이 아닙니다. 무어의 시계는 2년마다 정확히 2배인 이상적 모델입니다.

비용·위험 점수·작업 기간은 원리를 관찰하기 위한 게임 가정입니다. 실제 프로젝트의 고정 비용 비율, 예측치, 스크럼의 실제 반복 길이 등으로 해석하지 마세요.

실습의 작은 데이터와 시나리오는 직접 구성한 교육용 예시입니다. 실제 DBMS를 실행하거나 머신러닝 서비스를 호출하지 않습니다. 회귀 실습은 기울기·절편을 직접 조절하며 오차 감소를 체험하는 것으로 자동 경사하강법 구현은 아닙니다. 각 스테이지에 강의자료 파일명과 PDF 페이지가 있습니다.

진행 중인 개념 모험은 조작할 때마다 기기에 저장되고, 다시 같은 스테이지에 들어가 이어갈 수 있습니다. 초기 퀴즈 버전에서 쌓은 경험치와 오답도 유지합니다.

## 플레이

- 과목 → 챕터 → 유형(혼합·객관식·OX·단답형) → 10·20·전체 문제 선택
- 문항과 객관식 선택지를 매번 무작위로 구성
- 정답 10 XP, 3연속 정답부터 5 XP 추가, 100 XP마다 레벨 상승
- 정답·해설·원본 PDF 파일명과 페이지 표시
- 단답형: 답 입력 → 예시 답안 확인 → 직접 채점. Enter로 자가 채점을 건너뛸 수 없습니다.
- 오답 도감, 과목별 오답 필터, 이번 모험 오답 재도전, 최근 50회 결과 기록
- 자동 저장·이어하기·학습 기록 JSON 내보내기·초기화
- 선택형 타이머와 합성 효과음(기본 OFF), 키보드 조작, 모션 감소 설정 지원
- 최초 정상 접속 후 오프라인에서 다시 실행할 수 있도록 정적 파일 캐시

학습 기록은 브라우저의 localStorage(기기 안의 저장 공간)에 보관합니다. 다른 기기와 동기화되지 않으며, 브라우저 데이터 삭제 시 사라집니다. 내보내기는 백업용이며 게임 안에서 파일 가져오기는 지원하지 않습니다. 타이머 설정은 다음 모험부터 적용됩니다. 잠시 쉬기와 설정 창에서는 타이머를 일시 정지하고, 브라우저를 그대로 닫으면 기존 제한 시간이 유지됩니다.

문제는 실제 시험의 기출문제가 아니며 전체 출제 범위를 보장하지 않습니다. 출처 페이지는 **PDF의 첫 페이지부터 세는 1기준 페이지 번호**입니다. 자료 안에 있는 표지·제출 지시·평가 일정은 게임 제작 지시로 취급하지 않았습니다. 과제 안내의 제출 규정은 학습 문제에서 제외했고, 요청에 없던 Chapter 7도 제외했습니다. 강의계획과 과제 안내의 평가 항목 차이를 임의로 판단해 문제로 만들지 않았습니다.

반도체와 생성형 AI 디자인은 중간고사 범위인 2~7주차 강의자료로 출제했습니다. 1주차 오리엔테이션의 평가 방식·과제 안내와 강사 이력은 학습 문제에서 제외했습니다. 텍스트가 이미지로만 된 슬라이드는 화면을 직접 확인해 출제했습니다.

소프트웨어공학은 04·05 학습활동의 핵심 개념을 관련 본 강의자료와 대조했습니다. 강의자료의 판본별 프로세스 개수 등 혼동 가능성이 있는 수치는 출제하지 않았습니다. 원본 PDF나 개인 경로는 저장소에 포함하지 않습니다.

## GitHub Pages 배포

빌드나 외부 서버 없이 실행되는 HTML/CSS/JavaScript 사이트입니다. `/QUIZ-for-MidtermExam/` 같은 저장소 하위 경로에서도 동작하도록 모든 정적 파일 경로를 상대경로로 작성했습니다.

1. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
2. Branch를 **main**, 폴더를 **/(root)**로 선택하고 저장합니다.
3. 이후 `main` 브랜치에 파일을 반영하면 GitHub Pages가 자동으로 다시 게시합니다.

저장소 공개 범위는 변경하지 않습니다. 현재 Pages는 공개 사이트로 설정되어 있습니다. 원본 강의 PDF는 게시하지 않으며 게임과 직접 구성한 문제만 서비스합니다.

현재 GitHub 연결에는 Actions workflow 파일을 추가하는 권한이 없어, 별도 workflow 없이 GitHub Pages의 브랜치 게시 기능을 사용합니다. 배포 전 검증은 로컬에서 `npm test`로 실행할 수 있습니다.

## iPhone 17 Pro 대응

노치·홈 인디케이터·가로 방향을 위한 안전 여백, 48px 중심의 터치 버튼, 입력 시 확대를 줄이는 16px 입력 글자를 적용했습니다. iPhone 17 Pro의 브라우저 화면 설정을 사용하여 Chromium과 WebKit에서 세로·가로 터치 조작을 검사했습니다. **브라우저 에뮬레이션이며 실제 iPhone에서의 수동 검증을 대체하지 않습니다.** 주소창·키보드·화면 확대 설정 등 기기 환경에 따라 실제 표시 영역은 달라집니다.

## 로컬 실행과 검증

```sh
python3 -m http.server 4173
# http://localhost:4173 로 접속
npm test
```

파일을 직접 열기보다 로컬 웹서버를 사용하세요. 문제 JSON을 불러오고 모듈을 실행해야 합니다. `npm test`는 Node.js 22 이상에서 외부 패키지 설치 없이 실행됩니다.

네트워크 단절 검증(`test:offline`)은 자체 임시 서버에 대한 연결을 끊어 캐시 복구를 확인하며, 실행 후 서버를 종료합니다.

브라우저 통합 검증은 개발용 Playwright를 사용합니다. `npm test`는 28개 검증 묶음으로 문제 데이터와 실습 계산·완료 조건을 확인합니다.

```sh
npm install
npx playwright install chromium webkit
# 다른 터미널에서 로컬 서버를 먼저 실행한 뒤:
QUIZ_BASE_URL=http://localhost:4173 npm run test:browser
QUIZ_BASE_URL=http://localhost:4173 npm run test:concepts
QUIZ_BASE_URL=http://localhost:4173 npm run test:se
QUIZ_BASE_URL=http://localhost:4173 npm run test:sg
QUIZ_BASE_URL=http://localhost:4173 npm run test:offline
# Safari 계열 엔진으로 검사:
QUIZ_ENGINE=webkit QUIZ_BASE_URL=http://localhost:4173 npm run test:browser
QUIZ_ENGINE=webkit QUIZ_BASE_URL=http://localhost:4173 npm run test:concepts
QUIZ_ENGINE=webkit QUIZ_BASE_URL=http://localhost:4173 npm run test:se
QUIZ_ENGINE=webkit QUIZ_BASE_URL=http://localhost:4173 npm run test:offline
```

이미 설치된 Chrome을 쓰려면 `QUIZ_BROWSER_PATH`에 실행 파일 경로를 지정하세요. 브라우저 검증은 320~1280px 화면, 네 과목·네 문제 유형, 셔플 채점, 직접 채점 절차, 점수·경험치, 오답 재도전, 이어하기, 시간 초과를 확인합니다.

## 파일 구성

- `index.html`, `style.css`, `app.js`: 화면과 게임 흐름
- `engine.js`: 무작위 출제·선택지 셔플·객관식 채점
- `lessons.js`, `lesson-engine.js`: 20개 기초 실습의 화면·계산·진행 조건
- `se-classes.js`, `se-engine.js`: 소프트웨어공학 7개 추가 클래스의 화면·실습 로직
- `sg-classes.js`, `sg-engine.js`: 반도체와 생성형 AI 4개 스테이지의 화면·실습 로직
- `assets/questions.json`: 문항·정답·해설·출처 (수정 후 `npm test` 실행)
- `sw.js`, `manifest.webmanifest`: 오프라인 캐시·홈 화면 실행 정보
- `tests/`: 문제 데이터·채점 및 브라우저 통합 검증
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 게시

앱 자체는 외부 폰트·이미지·분석 도구·API 키에 의존하지 않습니다. 픽셀 그래픽은 직접 작성한 SVG/CSS, 효과음은 Web Audio 합성입니다. 참고한 [Gen_AI_Fixed](https://github.com/MING9UCCI/Gen_AI_Fixed)의 픽셀 게임·랜덤 문제·해설·오답 복습 방식을 바탕으로 네 과목용 화면과 로직을 새로 작성했습니다.
